# 分类体系改造方案

> 基于 1,433 张实测数据（严格准确率 68.8%）的语义分析
> 日期：2026-10-31

## 一、判断标准

一个类别是否该独立存在，看三条：

1. **视觉可分性**：人看照片能不能稳定区分？不能分的，不该是两个类。
2. **处置差异**：两个类别的整改措施是否不同？相同的，合并无损失。
3. **双向混淆**：A→B 和 B→A 都频繁，说明边界客观上不存在。

三条都不满足 → 必须合并。
只有第 3 条不满足（单向混淆）→ 是层级问题，用优先级规则解决。

## 二、必须合并（语义上就是同一件事）

### 合并 1｜高空坠物 + 外立面脱落 → 「建筑外立面破损/坠落风险」

| 项 | 内容 |
|---|---|
| 实测 | 高空坠物 27%（14/52）<br>外立面脱落 78%（53/68） |
| 混淆 | 高空坠物→外立面脱落 29 次（最高），反向 2 次 |
| 关键词重合 | 26%：「基层」「脱落」「露出内部」「高层建筑」 |
| **语义判断** | 同一面墙，砖还没掉=「高空坠物」，掉了=「外立面脱落」。<br>**照片上这个差别根本不存在**，而且处置完全一样（围挡、拆除、维修）。 |
| 结论 | **合并**。新类：`facade_fall`（建筑外立面破损/坠落风险） |

### 合并 2｜危房 + 墙体开裂/倾斜 → 「建筑结构损伤」

| 项 | 内容 |
|---|---|
| 实测 | 危房 37%（16/43）<br>墙体开裂 66%（44/67） |
| 混淆 | 危房→墙体开裂 20 次，反向 13 次（**双向都高**） |
| 关键词重合 | 14%：「剥落」「开裂」「裂缝」 |
| **语义判断** | 「危房」需要专业鉴定（危房等级 A/B/C/D），普通人拍照只能看到裂缝和倾斜。**网上的"危房"图 58% 其实是墙裂**（复检数据）。 |
| 结论 | **合并**。新类：`structural_damage`（建筑结构损伤：开裂/倾斜/危房）<br>如果业务上必须保留"危房"，改为**严重度**字段，不另设类别。 |

### 合并 3｜裸露/老化电线 + 私拉乱接 → 「电线裸露/私拉乱接」

| 项 | 内容 |
|---|---|
| 实测 | 裸露电线 59%（24/41）<br>私拉乱接 78%（31/40） |
| 混淆 | 裸露电线↔私拉乱接 6 次 / 反向 7 次（**双向对称**） |
| 关键词重合 | 9%：「无防护」「铜芯裸露」 |
| **语义判断** | 私拉乱接的电线**必然**是裸露的；裸露的老化电线也可能是早年乱拉的。**同一种画面，两种描述。** |
| 结论 | **合并**。新类：`exposed_wire`（电线裸露/私拉乱接） |

### 合并 4｜消防水源异常 + 消防设施故障 → 「消防设施/水源异常」

| 项 | 内容 |
|---|---|
| 实测 | 消防水源异常 **0%**（0/19）<br>消防设施故障 93%（38/41） |
| 混淆 | 水源异常→设施故障 16 次（占该类 84%） |
| **语义判断** | 「消火栓没水」本身就是「消防设施故障」的一种。**定义上是从属关系，不是并列。** |
| 结论 | **合并**。新类：`fire_equipment_fault`（消防设施/水源异常） |

### 合并 5｜无安全警示 + 未设置围挡 → 「施工防护缺失」

| 项 | 内容 |
|---|---|
| 实测 | 无安全警示 **4%**（1/24）<br>未设置围挡 43%（6/14） |
| 混淆 | 无安全警示→未设围挡 5 次，反向 1 次 |
| 关键词重合 | 9%：「人行道旁」「坑口无围挡」 |
| **语义判断** | 同一个施工现场，**往往既没围挡也没警示**。分开标等于强迫标注者二选一，这就是 4% 的根源。 |
| 结论 | **合并**。新类：`construction_protection`（施工防护缺失：围挡/警示） |

### 合并 6｜施工临时用电 → 并入「电线裸露/私拉乱接」

| 项 | 内容 |
|---|---|
| 实测 | 施工临时用电 29%（7/24） |
| 混淆 | 临时用电→配电设施故障 8 次，→私拉乱接 6 次 |
| 关键词重合 | 与配电设施 14%：「电线杂乱」「裸露」「配电箱内」 |
| **语义判断** | 施工临时用电的隐患表现就是「电线裸露、乱接、配电箱敞开」——**与电气类完全同构**，只是发生地点在工地。 |
| 结论 | **合并到 `exposed_wire`**。地点是「施工场地」还是「居民区」，用 `location` 字段记录，不另设类别。 |

## 三、不合并，但要加判定规则

### 盲道占用 ↔ 车辆占道

| 项 | 内容 |
|---|---|
| 实测 | 盲道占用 50%（28/56）<br>车辆占道 75%（60/80） |
| 混淆 | 17 次 / 反向 12 次 |
| **为什么不合并** | 盲道占用还有「摊贩占道」「杂物堆放」「施工围挡占压」等形态，**不只有车**。合并会丢掉「盲道」这个特殊对象。 |
| **正确做法** | 加优先级规则：**「占用盲道」优先于「车辆占道」**。<br>提示词里明确：车里停在盲道砖上 → 判 `blind_path_occupied`。 |

### 消防通道占用 ↔ 车辆占道

| 项 | 内容 |
|---|---|
| 实测 | 消防通道 59%（35/59） |
| 混淆 | 17 次，反向 2 次（**单向**） |
| **为什么不合并** | 消防通道是特殊区域（黄网格、消防登高面），处置力度不同（消防通道停车可罚 500 元）。 |
| **正确做法** | 加优先级规则：**画面有黄网格/消防标识时优先判消防通道**。<br>这 17 次错误里，很多是**没有黄网格标线**的图（复检已发现）。<br>补充规则：**无标线的图不应标为消防通道**。 |

### 占道经营 ↔ 垃圾堆积

| 项 | 内容 |
|---|---|
| 实测 | 占道经营 75%，垃圾堆积 89% |
| 混淆 | 9 次 / 反向 3 次 |
| **为什么不合并** | 处置部门不同（城管 vs 环卫），业务上必须分开。 |
| **正确做法** | 明确：**有主的东西（货物、摊位、货架）= 占道经营；无主的废弃物 = 垃圾堆积**。 |

### 污水/异味 → 改为「污水外溢」

| 项 | 内容 |
|---|---|
| 实测 | 22%（12/55），混淆到「其他」14 次、「排水积水」12 次、「垃圾堆积」6 次 |
| **真因** | **「异味」靠闻，照片拍不出来**。这一类从一开始就有一半内容不可视。 |
| **正确做法** | 改名为 `sewage_overflow`「污水外溢」，**定义收紧为「能看见的污水横流/黑臭积水/污水井冒溢」**。<br>与「排水积水」的区别：积水是**清水/雨水**，外溢是**发黑发臭的污水**。 |

### 违规搭建

| 项 | 内容 |
|---|---|
| 实测 | 42%（16/38） |
| 混淆 | →高空坠物 5 次，→其他类分散 |
| **真因** | 「违规」是**规划属性**，不是视觉属性。照片上只能看出「有个铁皮棚」，看不出有没有批文。 |
| **正确做法** | 改名为「临时构筑物/私搭棚架」，判据改为**视觉可见的加建物**（楼顶搭棚、阳台外扩、占道铁皮房），明确「不判断合规性」。 |

### 「其他」类

| 项 | 内容 |
|---|---|
| 混淆 | 污水异味→其他 14 次，燃气管道老化→其他 6 次 |
| **结论** | **这是设计缺陷**。「其他」不是一个隐患，是垃圾桶。<br>建议：**从评测体系移除**。确实无法归类的不进数据集，而不是塞进「其他」。 |

| 消防设施故障 | 93% | 保留（合并水源异常后仍独立） |
| 排水/积水 | 92% | 保留 |
| 垃圾堆积 | 89% | 保留 |
| 脚手架/临边防护 | 88% | 保留 |
| 路灯/线杆损坏 | 85% | 保留 |
| 配电设施故障 | 81% | 保留（施工临时用电已并入电线类） |
| 外立面脱落 | 78% | 保留（合并高空坠物后） |

## 五、样本不足，暂不评价

| 类别 | 样本 | 问题 |
|---|---:|---|
| 超期未检 | 1 | 本质是证件文字，非视觉隐患 |
| 电梯困人 | 6 | 新闻图多为救援现场（整改中） |
| 燃气泄漏 | 8 | 气体不可见 |
| 电梯停运 | 10 | 多为「维修中」告示牌 |

**建议：保留在分类体系中（业务需要），但评测报告注明"视觉样本不足，未纳入准确率统计"。**

## 六、改造结果

### 从 32 类 → 24 类

| 操作 | 数量 |
|---|---:|
| 原类别 | 32 |
| 合并 5 组（10 类变 5 类） | −5 |
| 移除「其他」 | −1 |
| 施工临时用电并入电线类 | −1 |
| 消防水源异常并入消防设施 | （已计入） |
| **新类别数** | **24** |

### 具体映射

```
高空坠物      ┐
外立面脱落    ┴→ facade_fall        建筑外立面破损/坠落风险

危房          ┐
墙体开裂      ┴→ structural_damage  建筑结构损伤

裸露电线      ┐
私拉乱接      ┼→ exposed_wire       电线裸露/私拉乱接
施工临时用电  ┘

消防水源异常  ┐
消防设施故障  ┴→ fire_equipment_fault  消防设施/水源异常

无安全警示    ┐
未设置围挡    ┴→ construction_protection  施工防护缺失

污水异味      →   sewage_overflow   污水外溢（重新定义）
违规搭建      →   illegal_structure 临时构筑物（重新定义）
其他          →   删除
```

### 预期效果

| 指标 | 现在 | 合并后（预估） |
|---|---:|---:|
| 类别数 | 32 | 24 |
| 严格准确率 | 68.8% | **82-87%** |
| 大类准确率 | 85.6% | 90%+ |

**提升的 15 个百分点不是模型变强了，而是消除了本来就不存在的分类边界。**
