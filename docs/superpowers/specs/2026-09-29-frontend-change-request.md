# 前端改动需求（2026-09-29）

> 用途：交给前端同学/模型执行。后端已上线（commit 见仓库），以下都是**前端要配合的部分**。
> 相关后端文档：`docs/superpowers/specs/2026-09-29-retract-and-image-hard-delete-design.md`

## 1. 隐患任务「撤回」按钮（必须做）

- **位置**：隐患列表项 + 隐患详情页
- **显示条件**：`item.status === 0 && item.userId === 当前登录用户 userId`
  （`0` = 待处理；只有**创建人本人**、且**还没被接单**时才能撤）
- **调用**：`POST /api/hazard/{id}/withdraw`，带 `Authorization: Bearer <token>`（无请求体）
- **成功**（`res.data.code === 200`）：用返回的 `data` 刷新该项 —— 它会带 `status: 5`、`statusText: "已撤回"`；也可直接从"待处理"列表里移除
- **确认弹窗文案（建议）**：`撤回后该上报记录只对管理员可见，确定撤回吗？`
- **失败处理（一定要读 `code`，HTTP 仍是 200）**：
  | code | 场景 | 前端动作 |
  | --- | --- | --- |
  | 409 | 已被接单/已受理 | toast `message`（"该任务已被受理，无法撤回"） |
  | 404 | 不是本人 / 不存在 | toast（"任务不存在或无权限"） |
  | 401 | 未登录/登录过期 | 清 token → 跳登录 |
- ⚠️ **状态值别搞混**：`5` = 已撤回；`4` = 已驳回（审核不通过）。`statusText` 后端已经给，直接渲染即可。
- ⚠️ **列表默认拿不到已撤回**（后端按角色过滤：普通用户、处理人都看不到）→ 前端**不需要**写过滤逻辑。

## 2. 管理员列表加「已撤回」筛选项（建议）

- 仅 `role === 1`（管理员）时显示；筛 `status === 5`。
- 管理员能看到已撤回、并且 `/api/hazard/stats` 里多了一个 `withdrawn` 字段（已撤回条数，**不计入 `total`/`rate`**），可以用它做统计卡。

## 3. 错误码语义变了（**必须检查现有错误分支**）

后端现在返回**有意义的 `code`**；⚠️ **HTTP 状态码保持 200**（axios 不会进 catch），所以**仍然必须读 `res.data.code`**：

| code | 含义 | 前端建议 |
| --- | --- | --- |
| 401 | 未登录 / 凭证错误（含"用户不存在""密码错误"） | 清 token → 跳登录 |
| 403 | 无权限（如普通用户调删除语料） | toast `message` |
| 404 | 不存在（含"已撤回的隐患对你不可见"） | toast / 从列表移除 |
| 409 | 状态冲突（如撤回已受理任务） | toast `message` |
| 400 | 参数错误（验证码错误/过期、文件为空/超 10MB/格式不支持） | toast `message` |
| 429 | 操作过于频繁（多为发验证码） | toast `message` |
| 500 | 其他 | 兜底"系统繁忙" |

> 之前这些**一律是 500**。如果前端是按 `code === 500` 做分支的，务必改成按语义分支。

## 4. 删除报告的语义变化（不用改代码，但要知道）

- 现在**服务端会同时删除 MinIO 里的图片**：删成功后，图片 URL 立刻 404。
- 若图片删不掉：后端返回 `code: 500` **且报告不会被删除**（数据保留，后台异步重试清理图片）
  → **前端不要在失败时乐观地从列表移除该项**，要等 `code === 200` 再移除。
- 报告详情响应结构**未变**（`imageKey` 后端标了 `@JsonIgnore`，不下发）。

## 5. 保存报告时，`imageUrl` 必须原样回传（**关键**）

- `POST /api/report` 的 `imageUrl` 必须是 `POST /api/upload/image` 返回的 `data.url` **原样回传**。
- 原因：后端会取该 URL 的最后一段作为 MinIO 对象 key，用于"删除报告时删图"和后台清理。
- ❌ 不要自己拼接、改协议、加签名参数或加 query（否则删报告时找不到图片对象，只能留下孤儿对象）。
