# 面试准备计划（2026-10-11 → 投递）

> 状态：current
> 最后核对：2026-10-14（**第四轮基线：软考优先制 + 投递 deadline 重定义**）
> 目标：**11/01 开始投递**。
> 说明：日历按周日为一周起始，星期标注已按 2026-10 实际日历核对。

## 0. 第四轮基线的由来（重要）

原计划按"每天 4–5h 全给主线"排，现实是：
白天上课只能复习软考（不能带电脑）、软考 10/24 必须过、期间又冒出项目真实缺陷要修。
→ 原计划**过度承诺**，会两头都做不好。所以改成下面的**两段式**。

## 1. 核心重定义：deadline 不是"投递日"，是"第一场面试"

投递只需要两件事：**简历能发** + **项目能讲 5 分钟版**。
八股深挖、yydp 细节、模拟面试**都可以放到投递之后、第一场面试之前**（投递到面试通常隔几天到一周）。

所以：**10/24 之前，软考绝对优先；主线只保留"最低维持量"。**

## 2. 每日时间模板

**阶段 A：10/14 – 10/23（软考优先，10 天）**

```
白天课间 / 碎片   软考知识点 + 项目讲稿口述（手机可读，不需要电脑）
晚上 1–1.5 h     45 min 软考刷题  +  20–30 min 项目讲稿（读文档 / 口述 / 记卡片）
周末（10/17–10/18）若能凑 2h，就做完一"层"项目讲稿
```

- **硬规则 A1：这 10 天不排八股深挖、不排算法新题。**
  理由：八股是"临时抱佛脚也有效"的内容，停 10 天不会归零；算法断了用 3 天就能捡回来。
- **硬规则 A2：软考 10/24 考完即完全放下**，不许再拖成第二条主线。

**阶段 B：10/25 – 10/31（全力，7 天 ≈ 30h）**

```
4–5 h/天：项目讲稿收口 / 简历 / 八股只挑 3 个模块 / 模拟面试
```

**阶段 C：11/01 起（面试期滚动）**

```
每天：算法 1 题(30min) + 1 个八股模块快速回顾(40min) + 1 段项目口述(30min) + 复盘上一场(20min)
未学完的八股模块（JVM / Spring / Redis / 网络+OS / 集合）在这里补
```
