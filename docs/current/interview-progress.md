## 9. 视觉评估集 v2.1 model_consensus

> 状态：evidence  
> 标签来源：`model_consensus`，不是人工 gold  
> 标注模型：`mimo-v2.6-flash` + `glm-5.3-flash`

### 9.1 最终数据

- 总计 160 张：80 正 / 80 负
- dev 80 张：40 正 / 40 负
- test 80 张：40 正 / 40 负
- 8 个大类各 10 个正样本，test 每类 5 个
- 候选主池 342 张，大类 Kappa 0.808，consensus yield 61.4%
- 补样 73 张 + 电梯补样 10 张，只补缺口类别
- 所有标签来源均为 `model_consensus`

### 9.2 冻结 test 结果

| 指标 | Baseline | Final |
|---|---:|---:|
| Recall | 95.0% | 92.5% |
| Precision | 76.0% | 92.5% |
| FPR | 30.0% | 7.5% |
| F1 | 84.4% | 92.5% |
| Macro Recall | 82.5% | 82.5% |
| Critical Miss Rate | 5.0% | 7.5% |

预注册 winner 为 baseline。final prompt 虽然把 FPR 从 30.0% 降到 7.5%、F1 从 84.4% 提到 92.5%，但 critical miss 从 5.0% 升到 7.5%，因此不能声称整体优化，只能作为召回-误报取舍。

### 9.3 面试可讲的三个错误

- `NEGMAN01`：工人用井盖钩开启完好井盖，模型把施工动作误判成施工无警示，属于硬负样本误报。
- `WAL0020`：墙端局部抹灰破损，baseline 大类混淆，final 直接漏报，说明精度优先会牺牲弱隐患召回。
- `DIS0079`：配电设备旁私拉插排，模型判成施工临时用电，gold 是电气线路问题，说明场景语境会压过设施本体类别。
