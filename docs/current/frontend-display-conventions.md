# 前端展示约定

> 状态：current
> 日期：2026-10-28

## 内部主键不直接展示

前端页面不得直接渲染数据库自增主键或内部用户 ID，包括但不限于：

- `#HAZ-{id}`
- `UID #{id}`
- `专员 #{handlerId}`
- `DOC-{id}`
- `hazard_code` 中的内部工单号

数据库主键仅用于：

- 路由参数
- API 请求
- Vue `key`
- 内部状态比较

## 用户可见替代信息

- 工单：使用描述摘要、类别、地址、状态、创建时间
- 上报人：使用“市民上报”等来源信息；如需姓名，后续增加展示用昵称字段
- 处理人员：使用昵称、邮箱或“已指派专员”
- 未指派：使用“尚未指派处理人员”
- 档案：使用报告标题、类别、创建时间

## 业务编号

如后续确实需要客服、审计或跨系统沟通编号，应新增独立业务编号字段，例如：

```text
HAZ-20261028-0063
```

不得直接把数据库 `id` 作为业务编号展示。
